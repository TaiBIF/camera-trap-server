Data Package 內容

每份資料集是一個資料夾，包含四個檔案。所有時間皆為台灣時間（+08:00），座標為 WGS84 經緯度，不需再轉換。

檔案一列代表分析時主要用途
deployments.csv一台相機在一個位置運作的一段期間樣點座標、相機工作時數
observations.csv一筆辨識結果物種、拍攝時間、年齡、性別
media.csv一張照片照片檔名、網址（多數分析用不到）
datapackage.json整份資料集的說明物種中文名、TaiCOL 編號、授權

三個編號

  • locationID：相機位置（樣點）。同一位置可能有多段運作期間，以樣點為單位分析時請用 locationID 分組。
  • deploymentID：一段運作期間，observations 以此對應到 deployments。
    • j- 開頭：有實際架設與回收紀錄，起訖時間精確。
    • dep- 開頭：早期資料沒有架設紀錄，一個位置只有一段期間，起訖時間是該位置第一張到最後一張照片的時間。
  • mediaID：一張照片。一張照片拍到兩種動物時，observations 會有兩列、共用同一個 mediaID。

最常用的欄位

檔案欄位內容
observationseventStart拍攝時間，例如 2022-05-04T10:37:10+08:00
observationsobservationTypeanimal 動物、blank 空拍或定時測試照、human 人員架設／回收相機
observationsscientificName學名（依 TaiCOL）；無法辨識到種的動物為空白
observationslifeStage、sex、observationTags年齡（成體、亞成體、幼體）、性別（雄性、雌性、無法判定）、鹿角狀態（如硬角一尖），皆為中文原始值
observationsobservationComments備註；學名空白時，原始中文辨識名稱放在最前面（如「鳥」「鼠」）
deploymentslatitude、longitude相機位置經緯度
deploymentsdeploymentStart、deploymentEnd運作期間起訖
deploymentstimestampIssuestrue 表示這段期間的照片時間可能有誤
deploymentsdeploymentGroups所屬樣區（如林業署各分署）
deploymentscameraHeight注意：此欄為相機位置的海拔（公尺），不是相機離地高度

完整欄位定義請參考 Camtrap DP 官方說明。

讀取資料

檔案很大：329 的 observations.csv 約 3.5 GB、兩千萬列，media.csv 約 4.8 GB，用 Excel 或一般 pandas read_csv 可能記憶體不足。建議使用 DuckDB，直接以 SQL 查詢 CSV，不需先載入記憶體。

pip install duckdb
import duckdb

con = duckdb.connect()
con.sql("""
    SELECT observationType, count(*) AS records
    FROM read_csv('observations.csv', quote = '"', escape = '"', all_varchar = true)
    GROUP BY observationType
""").show()

也可以在 DuckDB 命令列直接執行下文的 SQL。讀取 CSV 時請加上兩個設定：

  • quote = '"', escape = '"'：必須明確指定。DuckDB 只取樣檔案開頭數萬列來判斷格式，若樣本中剛好沒有引號，後面以引號包住、含逗號的備註（例如 "工作照 時間設置錯誤, 無法修正"）會被拆成多欄，查詢中途失敗。288 即會發生。
  • all_varchar = true：以文字讀入所有欄位。時間已是台灣時間，取字串前 10 碼即為日期、第 12–13 碼即為小時，可避免時區自動轉換造成的錯誤。

R 使用者可用 camtrapdp 套件讀取 datapackage.json；檔案較大時同樣建議搭配 DuckDB。

分析前的篩選

  • 只取動物：observationType = 'animal'空拍、定時測試照（blank）與人員架設、回收相機的工作照（human）不是物種紀錄。它們仍保留在資料中，可用來確認相機的運作狀況。
  • 學名空白的動物無法辨識到種的紀錄，如「鳥」「鼠或鼩形目」「無法辨識」，學名為空白。做物種層級分析時排除；需要較高分類階層時，可從 observationComments 開頭取得原始名稱。
  • 時間可能有誤的期間：timestampIssues = 'true'相機時鐘錯誤等原因，照片時間可能不正確（如 1980 年或未來日期）。分析活動時段、時間序列前建議排除。287 有 7 段、288 有 2 段、329 有 31 段。
  • 座標錯誤的樣點287、288 的 HL13B（緯度 2.34）、288 的 LD-LTMM-023（緯度 21.00）不在臺灣範圍內，空間分析時請排除，或以臺灣範圍（緯度 21.5–26.5、經度 118–123.5）篩選。
  • 早期資料的運作期間：dep-期間為第一張到最後一張照片，中間的停機空檔也被算入，工作時數會被高估、OI3 因而低估。比較不同樣點或年度時，建議將 j- 與 dep- 分開分析，或只使用 j-。
  • 329 的 2007 年資料早於計畫開始（2015 年），但未被判定為時間錯誤，可能是相機時鐘設定錯誤，使用時請留意。

常見分析

以下 SQL 在 Data Package 資料夾內執行。

物種與紀錄數

SELECT scientificName, count(*) AS records
FROM read_csv('observations.csv', quote = '"', escape = '"', all_varchar = true)
WHERE observationType = 'animal' AND scientificName IS NOT NULL
GROUP BY scientificName
ORDER BY records DESC;

中文名與 TaiCOL 物種編號見下一節中文名與 TaiCOL 編號。未辨識到種的原始名稱統計：

SELECT split_part(observationComments, ' ', 1) AS label, count(*) AS records
FROM read_csv('observations.csv', quote = '"', escape = '"', all_varchar = true)
WHERE observationType = 'animal' AND scientificName IS NULL
GROUP BY label
ORDER BY records DESC;

紀錄數是照片層級的計數，連拍會重複計算，不適合直接比較豐度，請使用下方的有效照片或 OI3。

中文名與 TaiCOL 編號

observations.csv 只有學名 scientificName。每份資料集的 datapackage.json 中有 taxonomic 清單，列出資料中出現的每個學名及其 TaiCOL 物種編號（taxonID）與中文名（vernacularNames.zho），以 scientificName 與 observations 對應：

"taxonomic": [
  {
    "scientificName": "Muntiacus reevesi",
    "kingdom": "Animalia",
    "taxonID": "t0096460",
    "vernacularNames": { "zho": "山羌" }
  },
  …
]

以 DuckDB 將中文名與 TaiCOL 編號併入物種統計：

WITH taxa AS (
  SELECT t.scientificName, t.vernacularNames.zho AS vernacularName, t.taxonID
  FROM (SELECT unnest(taxonomic) AS t FROM read_json('datapackage.json'))
)
SELECT o.scientificName, taxa.vernacularName, taxa.taxonID, count(*) AS records
FROM read_csv('observations.csv', quote = '"', escape = '"', all_varchar = true) o
LEFT JOIN taxa USING (scientificName)
WHERE o.observationType = 'animal' AND o.scientificName IS NOT NULL
GROUP BY ALL
ORDER BY records DESC;

TaiCOL 物種頁面網址為 https://taicol.tw/zh-hant/taxon/ 加上 taxonID，可查詢分類階層、保育等級與異名。

中文名的注意事項：datapackage.json 的中文名是資料中使用的原始辨識名稱，同一物種在不同資料集可能不同（例如「帝雉」與「黑長尾雉(帝雉)」、「深山竹雞」與「台灣山鷓鴣」）。跨資料集整合或發表時，請以 taxonID 為準，中文名建議使用下表的 TaiCOL 正式中文名。

另有 5 個物種 TaiCOL 已更新學名（表中註記「TaiCOL 現用學名」），資料中的學名仍為舊名，但 taxonID 相同，以 taxonID 對應不受影響。

相機工作時數

將同一樣點所有運作期間涵蓋的日期取聯集（重疊期間不重複計算），工作時數 = 工作天數 × 24。這與 TaiCAT 網站上計算 OI 值的方式相同。

WITH d AS (
  SELECT locationID,
         CAST(left(deploymentStart, 10) AS DATE) AS start_date,
         CAST(left(deploymentEnd, 10) AS DATE)   AS end_date
  FROM read_csv('deployments.csv', quote = '"', escape = '"', all_varchar = true)
  WHERE timestampIssues = 'false'
),
days AS (
  SELECT DISTINCT locationID,
         unnest(generate_series(start_date, end_date, INTERVAL 1 DAY)) AS day
  FROM d
)
SELECT locationID, count(*) AS working_days, count(*) * 24 AS working_hours
FROM days
GROUP BY locationID
ORDER BY locationID;

若需要特定月份或年度的工作時數，在 days 之後加上 WHERE day BETWEEN '2023-01-01' AND '2023-12-31'。

有效照片

動物停留在鏡頭前時會被連拍多張。為避免重複計算，同一樣點、同一物種在一段時間內的照片只算一次，稱為「有效照片」。常用間隔為 30 或 60 分鐘，報告結果時請註明所用的間隔。

有兩種常見定義，結果略有差異：

定義新的一筆的條件適用
與上一筆計入照片相隔距離上一張被計入的照片 ≥ 間隔與 TaiCAT 網站的 OI 值一致；見完整分析程式
與前一張照片相隔距離前一張照片（不論是否計入）≥ 間隔文獻中常見，可用 SQL 直接計算
-- 「與前一張照片相隔 ≥ 60 分鐘」的有效照片數
WITH a AS (
  SELECT d.locationID, o.scientificName,
         CAST(o.eventStart AS TIMESTAMPTZ) AS t
  FROM read_csv('observations.csv', quote = '"', escape = '"', all_varchar = true) o
  JOIN read_csv('deployments.csv', quote = '"', escape = '"', all_varchar = true) d USING (deploymentID)
  WHERE o.observationType = 'animal' AND o.scientificName IS NOT NULL
)
SELECT locationID, scientificName,
       count(*) FILTER (WHERE prev_t IS NULL OR t - prev_t >= INTERVAL 60 MINUTE)
         AS independent_photos
FROM (
  SELECT *, lag(t) OVER (PARTITION BY locationID, scientificName ORDER BY t) AS prev_t
  FROM a
)
GROUP BY locationID, scientificName;

OI3 相對豐度

OI3 ＝ 有效照片數 ÷ 相機工作時數 × 1000

即每 1,000 個相機工作小時的有效照片數。將上面兩個結果以 locationID 合併後相除即可。計算一段期間或一個區域的 OI3 時，請先分別加總有效照片數與工作時數，再相除，不要將各樣點的 OI3 直接平均。

注意：dep- 期間的工作時數被高估，OI3 會偏低；不同間隔、不同定義算出的 OI3 不可直接比較。

出現樣點比例

有拍到某物種的樣點數 ÷ 有工作時數的樣點總數，即 naive occupancy（未校正偵測率的出現比例）。若要進行占據模型（occupancy model）分析，可依 eventStart 的日期將每個樣點切成固定長度的調查期（如 7 天），並以工作時數判斷每期是否有相機運作。

活動時段

SELECT CAST(substr(eventStart, 12, 2) AS INTEGER) AS hour, count(*) AS records
FROM read_csv('observations.csv', quote = '"', escape = '"', all_varchar = true) o

  AND d.timestampIssues = 'false'

完整分析程式

以下 Python 程式一次產出四個表格，已套用分析前的篩選（排除時間可能有誤的期間與臺灣範圍外的樣點），有效照片採「與上一筆計入照片相隔 60 分鐘」。將程式存為 camtrap_analysis.py 後執行：

pip install duckdb
python camtrap_analysis.py project-329-林業署哺乳動物監測網 output-329
輸出檔案內容

effort_by_location.csv各樣點：名稱、經緯度、工作天數、工作時數
oi3_by_location.csv各樣點 × 物種：有效照片數、工作時數、OI3
activity_by_hour.csv各物種 0–23 時的有效照片數

以 329（兩千萬筆辨識）測試，執行約 20 秒。可在程式開頭調整 IMAGE_INTERVAL_MIN（間隔分鐘）與 EXCLUDE_TIMESTAMP_ISSUES。

展開程式碼 camtrap_analysis.py 
"""
Camtrap DP Data Package 基本分析：物種紀錄數、相機工作時數、OI3、出現樣點比例、活動時段。

用法：
    pip install duckdb
    python camtrap_analysis.py <Data Package 資料夾> [輸出資料夾]

輸出（UTF-8 BOM，可直接用 Excel 開啟）：
    species_summary.csv    各物種紀錄數、有效照片數、出現樣點數
    effort_by_location.csv 各相機位置的工作天數與工作時數
    oi3_by_location.csv    各相機位置 × 物種的 OI3
    activity_by_hour.csv   各物種 0–23 時的有效照片數
"""

import csv
import json
import sys
from pathlib import Path

import duckdb

IMAGE_INTERVAL_MIN = 60           # 有效照片的間隔門檻（分鐘）
EXCLUDE_TIMESTAMP_ISSUES = True   # 排除 timestampIssues = true 的相機期間
BBOX = (21.5, 26.5, 118.0, 123.5) # 臺灣範圍：緯度下限、上限、經度下限、上限


def write_csv(path, header, rows):
    with open(path, 'w', newline='', encoding='utf-8-sig') as f:
        w = csv.writer(f)
        w.writerow(header)
        w.writerows(rows)


def main(pkg, out):
    pkg, out = Path(pkg), Path(out)
    out.mkdir(parents=True, exist_ok=True)
    con = duckdb.connect()

    # 所有欄位先以文字讀入：時間已是 +08:00，直接取字串前 10 碼為日期、第 12–13 碼為小時。
    # quote 需明確指定：DuckDB 只取樣前幾萬列判斷格式，若樣本中沒有引號，
    # 之後含逗號的備註（以引號包住）會被拆錯欄而讀取失敗。
    con.execute(f"""
        CREATE VIEW deployments AS
        SELECT * FROM read_csv('{pkg / 'deployments.csv'}', header=true, quote='"', escape='"',
                          all_varchar=true)
    """)
    con.execute(f"""
        CREATE VIEW observations AS
        SELECT * FROM read_csv('{pkg / 'observations.csv'}', header=true, quote='"', escape='"',
                          all_varchar=true)
    """)

    lat_min, lat_max, lon_min, lon_max = BBOX
    ts_filter = "AND timestampIssues = 'false'" if EXCLUDE_TIMESTAMP_ISSUES else ''
    con.execute(f"""
        CREATE TABLE good_deployments AS
        SELECT deploymentID, locationID, locationName,
               CAST(latitude AS DOUBLE) AS latitude, CAST(longitude AS DOUBLE) AS longitude,
               CAST(left(deploymentStart, 10) AS DATE) AS start_date,
               CAST(left(deploymentEnd, 10) AS DATE) AS end_date
        FROM deployments
        WHERE CAST(latitude AS DOUBLE) BETWEEN {lat_min} AND {lat_max}
          AND CAST(longitude AS DOUBLE) BETWEEN {lon_min} AND {lon_max}
          {ts_filter}
    """)

    # 相機工作天數：同一位置各期間涵蓋的日期取聯集（重疊不重複計算），工作時數 = 天數 × 24
    effort = con.execute("""
        WITH days AS (
            SELECT DISTINCT locationID,
                   unnest(generate_series(start_date, end_date, INTERVAL 1 DAY)) AS day
            FROM good_deployments
        )
        SELECT d.locationID, any_value(g.locationName), any_value(g.latitude),
               any_value(g.longitude), count(DISTINCT d.day) AS working_days,
               count(DISTINCT d.day) * 24 AS working_hours
        FROM days d JOIN good_deployments g USING (locationID)
        GROUP BY d.locationID ORDER BY d.locationID
    """).fetchall()
    write_csv(out / 'effort_by_location.csv',
              ['locationID', 'locationName', 'latitude', 'longitude',
               'working_days', 'working_hours'], effort)
    hours_by_loc = {r[0]: r[5] for r in effort}

    # 動物照片（有學名），依位置、物種、時間排序
    rows = con.execute("""
        SELECT g.locationID, o.scientificName, o.eventStart
        FROM observations o JOIN good_deployments g USING (deploymentID)
        WHERE o.observationType = 'animal' AND o.scientificName IS NOT NULL
        ORDER BY g.locationID, o.scientificName, o.eventStart
    """)

    # 有效照片：與上一張「計入」的照片相隔 >= IMAGE_INTERVAL_MIN 才算新的一張
    threshold = IMAGE_INTERVAL_MIN * 60
    from datetime import datetime
    records = {}      # species -> 紀錄數
    independent = {}  # (location, species) -> 有效照片數
    by_hour = {}      # (species, hour) -> 有效照片數
    key = last_counted = None
    while batch := rows.fetchmany(100_000):
        for loc, sp, ts in batch:
            records[sp] = records.get(sp, 0) + 1
            t = datetime.fromisoformat(ts)
            if (loc, sp) != key:
                key, last_counted = (loc, sp), None
            if last_counted is None or (t - last_counted).total_seconds() >= threshold:
                last_counted = t
                independent[key] = independent.get(key, 0) + 1
                by_hour[(sp, t.hour)] = by_hour.get((sp, t.hour), 0) + 1

    # 中文名與 TaiCOL 編號取自 datapackage.json
    meta = json.loads((pkg / 'datapackage.json').read_text(encoding='utf-8'))
    taxa = {t['scientificName']: t for t in meta.get('taxonomic', [])}

    n_locations = len(hours_by_loc)
    species_rows = []
    for sp, n in records.items():
        locs = [loc for (loc, s) in independent if s == sp]
        species_rows.append([
            sp, taxa.get(sp, {}).get('vernacularNames', {}).get('zho', ''),
            taxa.get(sp, {}).get('taxonID', ''), n,
            sum(independent[(loc, sp)] for loc in locs), len(locs),
            round(len(locs) / n_locations, 4) if n_locations else '',
        ])
    species_rows.sort(key=lambda r: -r[4])
    write_csv(out / 'species_summary.csv',
              ['scientificName', 'vernacularName', 'taxonID', 'records',
               'independent_photos', 'locations_detected', 'naive_occupancy'],
              species_rows)

    oi3_rows = []
    for (loc, sp), n in sorted(independent.items()):
        hours = hours_by_loc.get(loc, 0)
        oi3_rows.append([loc, sp, n, hours, round(n / hours * 1000, 4) if hours else ''])
    write_csv(out / 'oi3_by_location.csv',
              ['locationID', 'scientificName', 'independent_photos', 'working_hours', 'OI3'],
              oi3_rows)

    write_csv(out / 'activity_by_hour.csv', ['scientificName', 'hour', 'independent_photos'],
              [[sp, h, n] for (sp, h), n in sorted(by_hour.items())])

    print(f'image interval: {IMAGE_INTERVAL_MIN} min; locations: {n_locations}; '
          f'species: {len(records)}; output: {out}')


if __name__ == '__main__':
    if len(sys.argv) < 2:
        sys.exit('用法：python camtrap_analysis.py <Data Package 資料夾> [輸出資料夾]')
    main(sys.argv[1], sys.argv[2] if len(sys.argv) > 2 else 'analysis-output')
